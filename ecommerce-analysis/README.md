# E-commerce Data Cleaning Project

## 📊 Project Overview
This project focuses on cleaning and analyzing a real-world e-commerce dataset using Python (Pandas).

## 📁 Dataset
Original dataset:
[https://www.kaggle.com/datasets/your-dataset-link](https://www.kaggle.com/datasets/carrie1/ecommerce-data)

- Cleaned sample dataset
- Visualizations (charts)

- Handling missing values
- Removing invalid records
- Feature engineering (Revenue calculation)
- Data visualization
